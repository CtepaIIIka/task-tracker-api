## Описание проекта

REST API для управления задачами. Проект написан на Java с использованием Spring Boot и позволяет выполнять полный цикл CRUD-операций: создавать, читать, обновлять и удалять задачи. Данные хранятся во встроенной базе данных H2.
Он демонстрирует навыки работы с современным бэкенд-стеком и архитектурой REST API.

## Стек технологий

- **Java 17** — язык программирования
- **Spring Boot 3.2.0** — фреймворк для создания REST API
- **Spring Data JPA** — работа с базой данных
- **H2 Database** — встроенная реляционная база данных
- **Maven** — сборка проекта и управление зависимостями
- **Lombok** — сокращение шаблонного кода

## Эндпоинты (API)

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /tasks | Получить список всех задач |
| GET | /tasks/{id} | Получить задачу по ID |
| POST | /tasks | Создать новую задачу |
| PUT | /tasks/{id} | Обновить существующую задачу |
| DELETE | /tasks/{id} | Удалить задачу |

### Создание задачи (POST /tasks)

Как запустить
Клонируйте репозиторий:

bash
git clone https://github.com/CtepaIIIka/task-tracker-api.git
Откройте проект в IntelliJ IDEA.

Дождитесь загрузки зависимостей Maven.

Запустите класс TaskTrackerApplication.java.

После запуска API будет доступен по адресу:


http://localhost:8080
Для просмотра базы данных перейдите по адресу:


http://localhost:8080/h2-console

User: sa

Password: оставить пустым
